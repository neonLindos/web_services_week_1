# Домашняя работа — Модуль 01

**Тема:** Введение в ASP.NET Core, первая конечная точка в API
**Проект:** `WebApiLab1` (Student)

## Как запустить

```bash
cd homework
dotnet run
```

Swagger UI откроется по адресу из вывода консоли (обычно `http://localhost:5256/swagger`).

## Что реализовано

- `GET /api/students` — список всех студентов → `200 OK`.
- `GET /api/students/{id}` — студент по Id (пункт 6, индивидуальное задание) → `200 OK`, либо `404 Not Found`, если студента с таким Id нет.
- `POST /api/students` — добавление нового студента, Id генерируется автоматически.

## Контрольные вопросы

1. **Что такое Web API?** — программный интерфейс, через который одно приложение (клиент) обращается по сети к другому (серверу) с помощью HTTP-запросов и получает данные, обычно в формате JSON, без графического интерфейса.
2. **Что такое HTTP-запрос?** — сообщение, которое клиент отправляет серверу; состоит из метода (GET, POST…), URL, заголовков и, при необходимости, тела запроса.
3. **Что такое HTTP-ответ?** — сообщение, которое сервер возвращает клиенту после обработки запроса; содержит код статуса, заголовки и тело с данными.
4. **Для чего используется метод GET?** — для получения данных с сервера без изменения его состояния.
5. **Для чего используется метод POST?** — для создания нового ресурса / отправки данных на сервер.
6. **Что означает код 200 OK?** — запрос успешно обработан, сервер вернул ожидаемый результат.
7. **Что означает код 404 Not Found?** — запрошенный ресурс с указанным идентификатором не найден.
8. **Что такое JSON?** — текстовый формат обмена данными (JavaScript Object Notation) в виде пар "ключ-значение" и массивов; компактен и легко читается человеком и программой.
9. **Что такое endpoint?** — конкретный адрес API (URL + HTTP-метод), по которому можно выполнить определённую операцию, например `GET /api/students`.
10. **Для чего используется Swagger?** — для автоматической генерации документации по API и интерактивного тестирования его endpoint'ов прямо в браузере, без написания отдельного клиента.
