## Цель работы

Познакомиться с принципами работы Web API и научиться создавать простой веб-сервис на C# с использованием ASP.NET Core и Visual Studio.

В ходе лабораторной работы необходимо:

- создать ASP.NET Core Web API;
- реализовать HTTP GET-запрос;
- реализовать HTTP POST-запрос;
- получить данные в формате JSON;
- протестировать API через Swagger.

## 1. Создание проекта

В Visual Studio создайте проект: **ASP.NET Core Web API**

Название проекта: **WebApiLab1**

При создании проекта:

- язык — C#;
- использовать Controllers;
- включить OpenAPI/Swagger;
- включить HTTPS.

Запустите проект и убедитесь, что Swagger открывается в браузере.

## 2. Создание модели

Создайте папку: **Models**

Создайте класс: **Student.cs**

```csharp
public class Student
{
    public int Id { get; set; }

    public string Name { get; set; } = string.Empty;

    public int Age { get; set; }
}
```

## 3. Создание Controller

Создайте контроллер: **StudentsController**

Добавьте следующий код:

```csharp
[ApiController]
[Route("api/[controller]")]
public class StudentsController : ControllerBase
{
    private static readonly List<Student> students = new()
    {
        new Student
        {
            Id = 1,
            Name = "Ayan",
            Age = 20
        },

        new Student
        {
            Id = 2,
            Name = "Dana",
            Age = 21
        }
    };
}
```

## 4. GET-запрос

Добавьте метод:

```csharp
[HttpGet]
public ActionResult<List<Student>> GetStudents()
{
    return Ok(students);
}
```

Запустите приложение.

В Swagger выполните: `GET /api/students`

Ожидаемый HTTP-код: **200 OK**

Пример ответа:

```json
[
  {
    "id": 1,
    "name": "Ayan",
    "age": 20
  },
  {
    "id": 2,
    "name": "Dana",
    "age": 21
  }
]
```

## 5. POST-запрос

Добавьте метод:

```csharp
[HttpPost]
public ActionResult<Student> AddStudent(Student student)
{
    student.Id = students.Count + 1;

    students.Add(student);

    return Ok(student);
}
```

Через Swagger отправьте:

```json
{
  "name": "Arman",
  "age": 22
}
```

После этого повторно выполните: `GET /api/students`

Новый студент должен появиться в списке.

## 6. Индивидуальное задание

Самостоятельно добавьте метод: `GET /api/students/{id}`

Например: `GET /api/students/1`

Метод должен возвращать одного студента.

Если студент с указанным Id отсутствует, API должен вернуть: **404 Not Found**
