## 1. Цель работы

В рамках практической работы студент должен познакомиться с принципами работы веб-сервисов и реализовать первое Web API на языке C# с использованием ASP.NET Core.

В результате выполнения работы студент должен понимать:

- что такое клиент и сервер;
- что такое Web API;
- как клиент отправляет HTTP-запрос серверу;
- из каких частей состоит HTTP-запрос;
- что такое URL и endpoint;
- для чего используются HTTP-методы GET, POST, PUT и DELETE;
- что такое HTTP Status Code;
- как Web API возвращает данные в формате JSON;
- как протестировать API через Swagger.

## 2. Используемые технологии

Для выполнения работы необходимо использовать:

- Visual Studio 2022 или более новую версию;
- C#;
- ASP.NET Core Web API;
- .NET 8 или актуальную LTS-версию .NET, установленную в компьютерном классе;
- Swagger / OpenAPI.

Использование базы данных в данной практической работе не требуется. Данные должны храниться в памяти приложения.

## 3. Постановка задачи

Необходимо разработать простой веб-сервис для управления списком учебных курсов университета.

Web API должен позволять:

- получить список всех курсов;
- получить один курс по его идентификатору;
- добавить новый курс;
- изменить существующий курс;
- удалить курс.

Взаимодействие с Web API должно выполняться посредством HTTP-запросов.

## 4. Модель данных

Создайте класс `Course`.

```csharp
public class Course
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Teacher { get; set; }
    public int Credits { get; set; }
}
```

Пример объекта:

```json
{
  "id": 1,
  "name": "Web Services",
  "teacher": "Ivan Ivanov",
  "credits": 5
}
```

## Задание №2. Получение курса по ID

Реализуйте: `GET /api/courses/{id}`

Например: `GET /api/courses/1`

```csharp
[HttpGet("{id}")]
public ActionResult<Course> GetById(int id)
{
    var course = courses.FirstOrDefault(x => x.Id == id);

    if (course == null)
    {
        return NotFound();
    }

    return Ok(course);
}
```

Проверьте: `GET /api/courses/1` → ожидаемый результат **200 OK**

Теперь выполните: `GET /api/courses/100` → ожидаемый результат **404 Not Found**
