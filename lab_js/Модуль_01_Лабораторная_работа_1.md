# Лабораторная работа №1

**Дисциплина:** «Разработка Web-сервисов»
**Тема:** Разработка простого Web-сервиса с использованием REST API

## Цель работы

Изучить принципы разработки Web-сервисов, познакомиться с архитектурой REST, HTTP-методами и научиться создавать простой сервер, предоставляющий API для работы с данными.

## Задание

Разработать Web-сервис для управления списком студентов.

Web-сервис должен предоставлять возможность:

- получить список всех студентов;
- получить информацию о конкретном студенте;
- добавить нового студента;
- изменить данные студента;
- удалить студента.

Для взаимодействия с сервером использовать REST API и HTTP-методы GET, POST, PUT и DELETE.

## Используемые технологии

HTML5; CSS3; JavaScript; Node.js; Express.js; JSON; REST API; HTTP.

## 1. Теоретические сведения

Web-сервис — программная система, предоставляющая определённые функции через сеть и позволяющая взаимодействовать с другими программами.

Одним из наиболее распространённых подходов к созданию Web-сервисов является REST (Representational State Transfer).

REST-сервис использует стандартные HTTP-методы:

| Метод | Назначение |
|---|---|
| GET | Получение данных |
| POST | Создание нового объекта |
| PUT | Изменение существующего объекта |
| DELETE | Удаление объекта |

Например, для работы со студентами можно использовать адрес `/api/students`.

Запрос `GET /api/students` возвращает список студентов. Запрос `POST /api/students` создаёт нового студента.

Данные между клиентом и сервером удобно передавать в формате JSON.

## 3. Разработка сервера

Создать файл `server.js`:

```js
const express = require("express");

const app = express();
const PORT = 3000;

app.use(express.json());
app.use(express.static("public"));

let students = [
    { id: 1, name: "Иван Иванов", group: "ИС-21" },
    { id: 2, name: "Петр Петров", group: "ИС-21" }
];

// GET — получение всех студентов
app.get("/api/students", (req, res) => {
    res.json(students);
});

// GET — получение одного студента
app.get("/api/students/:id", (req, res) => {
    const id = Number(req.params.id);
    const student = students.find(s => s.id === id);

    if (!student) {
        return res.status(404).json({ message: "Студент не найден" });
    }

    res.json(student);
});

// POST — добавление студента
app.post("/api/students", (req, res) => {
    const { name, group } = req.body;

    if (!name || !group) {
        return res.status(400).json({ message: "Необходимо указать имя и группу" });
    }

    const student = {
        id: students.length > 0 ? Math.max(...students.map(s => s.id)) + 1 : 1,
        name,
        group
    };

    students.push(student);

    res.status(201).json(student);
});

// PUT — изменение студента
app.put("/api/students/:id", (req, res) => {
    const id = Number(req.params.id);
    const student = students.find(s => s.id === id);

    if (!student) {
        return res.status(404).json({ message: "Студент не найден" });
    }

    const { name, group } = req.body;

    if (name) student.name = name;
    if (group) student.group = group;

    res.json(student);
});

// DELETE — удаление студента
app.delete("/api/students/:id", (req, res) => {
    const id = Number(req.params.id);
    const index = students.findIndex(s => s.id === id);

    if (index === -1) {
        return res.status(404).json({ message: "Студент не найден" });
    }

    const deletedStudent = students.splice(index, 1);

    res.json({ message: "Студент удалён", student: deletedStudent[0] });
});

app.listen(PORT, () => {
    console.log(`Сервер запущен: http://localhost:${PORT}`);
});
```

```bash
node server.js
```

## 6. Проверка REST API

Открыть в браузере `http://localhost:3000` либо выполнить запросы через Postman / curl:

- `GET /api/students` — список студентов;
- `GET /api/students/1` — один студент;
- `POST /api/students` с телом `{ "name": "...", "group": "..." }` — добавление;
- `PUT /api/students/1` — изменение;
- `DELETE /api/students/1` — удаление.
