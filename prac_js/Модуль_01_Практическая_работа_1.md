# Практическая работа №1

**Тема:** Разработка простого веб-сервера на Node.js с обработкой HTTP-запросов, маршрутизацией и подключением к базе данных

**Цель работы:** Создать простой веб-сервер на Node.js, научиться обрабатывать запросы и получать данные из базы данных.

## 1. Создание проекта

Создаём папку: `web-server`

В ней создаём файл: `server.js`

Открываем терминал в этой папке и выполняем:

```bash
npm init -y
npm install express sqlite3
```

## 2. Код сервера

В файл `server.js`. Полный листинг — в файле [server.js](server.js).

## 3. Запуск

В терминале:

```bash
node server.js
```

Появится: `Сервер запущен: http://localhost:3000`

## 4. Маршруты

В программе используются три маршрута:

- `GET /` — проверка работы сервера;
- `GET /users` — получение пользователей из базы данных;
- `POST /users` — добавление нового пользователя.
